# A11y checklist

Run on every screen and component before declaring done. Any violation fails the gate.

- [ ] WCAG AA on every text and UI pair (4.5:1 body, 3:1 large text and UI).
- [ ] Every interactive element keyboard-operable (Tab, Enter, Space, Escape, Arrow as appropriate).
- [ ] Focus ring visible on every interactive element.
- [ ] Every form field has a visible label (placeholder is not a label).
- [ ] Every image has alt text (decorative images get alt="").
- [ ] Reduced-motion preference respected.
- [ ] No meaning encoded in color alone (always pair with icon or text).
- [ ] No meaning encoded in icon alone (always pair with label or tooltip).
- [ ] Every modal traps focus and offers Escape.
- [ ] Touch targets at least 44 by 44 px.
- [ ] No auto-playing audio or video without a pause control.
- [ ] Skip-to-content link is the first focusable element on every page.
- [ ] Headings nest in order (no skipping levels).
