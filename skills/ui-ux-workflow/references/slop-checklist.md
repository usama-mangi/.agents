# Slop checklist

Run this on every screen and component before declaring done. Any match is a violation. Fix before ship.

## Fonts

- [ ] No Inter as the only family.
- [ ] No Geist, Space Grotesk, Instrument Serif, or JetBrains Mono as the lone brand mark.
- [ ] No Inter plus serif-italic accent combo on every page.

## Color

- [ ] No Tailwind indigo or violet as the brand accent.
- [ ] No purple-to-blue gradient heroes.
- [ ] No medium-grey body text in dark mode (fails WCAG AA).
- [ ] No coloured shadows or glows on every element.
- [ ] No gradient buttons or CTAs.

## Layout

- [ ] No centred Inter hero with a badge floating above the H1.
- [ ] No 3+ equal CTAs per section.
- [ ] No scroll-reveal fade-in on every element.
- [ ] No animation on every element at once.
- [ ] No mobile tap target under 44 by 44 px.

## Imagery

- [ ] No stock "multicultural team laughing" hero photos.
- [ ] No abstract 3D blobs.
- [ ] No emoji as section icons.
- [ ] No AI-generated images with artefacts.

## Copy

- [ ] Headline passes the name-swap test (replace the brand name with a competitor; if it still fits, rewrite).
- [ ] No buzzword copy ("empower", "unlock", "elevate", "seamless", "leverage").
- [ ] No superheading plus generic headline combo.
